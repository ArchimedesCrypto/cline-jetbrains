# Documentation Plan

## Goal
Provide comprehensive documentation for users and developers.

## Why
- Explain usage and features
- Facilitate contributions and maintenance

## Approach
- User Guide (docs/user-guide.md):
  - Installation steps
  - How to use chat, overlays (History, Settings, Account, MCP, Tools)
  - Configuring API keys, models, settings
  - Approving tools and commands
- Developer Guide (docs/developer-guide.md):
  - Project setup and build instructions
  - Overview of architecture (UI, Services, Core)
  - Guide for adding new tools
  - Guide for adding new API providers
- README.md Update:
  - Update main project README with info about the Java version

## Steps
1. Create docs/user-guide.md
2. Write installation section
3. Write basic usage section
4. Write settings section
5. Write tool/command approval section
6. Create docs/developer-guide.md
7. Write project setup section
8. Write architecture overview
9. Write guide for adding tools
10. Write guide for adding providers
11. Update main README.md
