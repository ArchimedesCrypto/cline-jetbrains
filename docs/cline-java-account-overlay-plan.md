# Account Overlay Plan

## Goal
Implement the Account view overlay.

## Why
- React UI has Account view
- Needed for parity
- User authentication and management

## Approach
- Create AccountView.java (JPanel)
- Add UI elements:

  - API Key field
  - Account info display
- Style to match React UI
- Add to ClineToolWindowContent overlay
- Add toolbar button to toggle
