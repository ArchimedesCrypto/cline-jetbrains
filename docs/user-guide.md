# Cline for JetBrains - User Guide

## Introduction

Welcome to Cline for JetBrains IDEs! This guide will help you get started with using Cline to enhance your development workflow with AI assistance directly within IntelliJ IDEA, PyCharm, WebStorm, and other JetBrains IDEs.

## Installation

1.  **Download:** Obtain the plugin `.zip` file from the release page or build it from source.
2.  **Install:**
    *   Open your JetBrains IDE.
    *   Go to `Settings/Preferences` > `Plugins`.
    *   Click the gear icon ⚙️ and select `Install Plugin from Disk...`.
    *   Choose the downloaded `.zip` file.
    *   Restart the IDE when prompted.
3.  **Open Cline:** Find the "Cline" tool window (usually on the right side panel) and open it.

## Basic Usage

### Chat Interface
The main interface is the Chat view.

*   **Starting a Task:** Type your development task or question into the input area at the bottom and press `Ctrl+Enter` or click the "Send" button.
*   **Conversation Flow:** Cline will respond, potentially asking clarifying questions or suggesting actions (like using tools or running commands).
*   **Messages:** Conversations consist of messages from you (User) and Cline (Assistant). Cline's messages may include formatted text, code blocks, images, tool requests, or command requests.

### Toolbar Navigation
Use the toolbar buttons at the top to access different views:

*   **New Task:** Clears the current chat and starts a fresh conversation.
*   **History:** Opens the History overlay to browse past conversations.
*   **Settings:** Opens the Settings overlay to configure the plugin.
*   **Account:** Opens the Account overlay to manage login and API keys.
*   **MCP:** Opens the MCP overlay to manage connected MCP servers.
*   **Tools:** Opens the Tool Test overlay for developers to test tools.
