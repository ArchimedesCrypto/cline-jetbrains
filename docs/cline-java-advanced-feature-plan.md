# Advanced Feature Completion Plan

## Goal
Implement all advanced features to reach 100% parity with the React version.

## Why
- Complete functionality
- Match React UI exactly
- Improve usability

## Approach
- **Account Overlay:**
  - Login/logout flow
  - API key management
  - Account info display
  - Error handling
- **MCP Overlay:**
  - List connected servers
  - Connect/disconnect servers
  - List tools/resources per server
  - Execute MCP tools
  - View MCP resource details
- **Context Menus:**
  - Copy text/code
  - Retry message
  - Delete message
  - Edit message
  - Icons and keyboard shortcuts
- **Image Thumbnails:**
  - Show thumbnails in ChatView
  - Click to zoom/preview
  - Support multiple images
- **History Search/Filter:**
  - Search bar
  - Filter by date, title, content
  - Highlight matches
- **Tool Auto-Approval UI:**
  - Per-tool approval settings
  - Global approval toggle
- **Command Approval UI:**
  - Per-command approval settings
  - Global approval toggle
- **Loading Indicators:**
  - API requests
  - Tool execution
  - Command execution
- **Error Feedback:**
  - Toasts
  - Inline errors
  - Retry options

## Steps
1. Implement Account overlay features
2. Implement MCP overlay features
3. Add full context menus
4. Add image thumbnail zoom
5. Add History search/filter
6. Add tool/command approval UI
7. Add loading indicators
8. Add error feedback
9. Test all features
